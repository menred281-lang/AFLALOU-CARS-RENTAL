Vehicle image policy
====================

The fleet uses local 1200px photographs sourced from Wikimedia Commons. Each
photo was checked against the named model, generation and (where the source
identifies it) trim. Source, author and license links are exposed in the site
footer and in each vehicle-details modal.

designed to show an "Image temporarily unavailable" state instead.
